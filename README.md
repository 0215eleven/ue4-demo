# ue4-demo · 黑神话网页端实验

一个实验性项目：探索把「黑神话」风格的动作场景搬到浏览器里跑，验证 UE4 资产 + Web 渲染的可行性。

> 非官方粉丝实验，与游戏科学（Game Science）无关，不含任何官方资产。

## 目标
- 在浏览器里跑一个可交互的小场景：角色移动、镜头跟随、一套基础棍法连招
- 帧率目标：中端笔记本 Chrome 下 60fps
- 加载体积控制在 50MB 以内

## 架构规划
- **渲染**：Three.js（WebGL2），预留 WebGPU 分支；UE4 导出的模型/动画转 glTF 2.0 + Draco/KTX2 压缩
- **角色与战斗**：状态机驱动动作（待机/移动/闪避/轻击/重击），动画混合用骨骼 AnimationMixer，命中检测用简化胶囊体
- **物理**：Rapier（WASM）处理碰撞与地形
- **资源管线**：UE4 → FBX → Blender 清理 → glTF 脚本批量转换，按场景分包懒加载
- **AI 辅助**：用 AI 编程代理生成和迭代游戏逻辑、着色器与测试
- **部署**：Vite 构建，静态托管（GitHub Pages / Cloudflare Pages）
